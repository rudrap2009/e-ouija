# E-Ouija

A lightweight browser-based Ouija board.

## What it is

It’s just a fun, lightweight digital Ouija board that runs right in your web browser. You type in a yes or no question, watch the planchette move around, and enjoy a casual, slightly spooky vibe.

There's no backend, no database and nothing to install. Just open index.html and start playing.


## Features

- Classic spirit-board style interaction in your browser

- Smooth planchette movement

- Simple yes-or-no question flow

- Zero setup or installation required

## Motivation

I wanted to see what a digital Ouija board would look like as a quick, horror game. It’s not trying to be a serious paranormal simulator just a fun, simple project to remind me that web apps don't always need massive infrastructure to be entertaining.

## Tools

- **HTML5** – Structure and markup for the board and UI
- **CSS3** – Styling animations and responsive design
- **JavaScript (Vanilla)** – Core interactivity and planchette movement logic
- **No frameworks or build tools** – Pure browser-native code for maximum portability
- **No backend** – Fully client-side application with no server dependency

## Run locally

```bash
git clone https://github.com/rudrap2009/e-ouija.git
cd e-ouija
```

Then open `index.html` in your browser.

No build step or install is required.
